# frontend

Flutter web frontend for KronTech.

## Google login with Firebase

Google login uses Firebase Auth through FlutterFire:

- Firebase is initialized in `lib/main.dart`.
- Firebase web config lives in `lib/firebase_options.dart`, generated by FlutterFire CLI.
- The frontend signs in with Google and Firebase keeps the session.
- The Django backend validates Firebase ID tokens from `Authorization: Bearer <token>`.

Run locally:

```bash
flutter run -d chrome
```

Firebase Console requirements:

- Authentication > Sign-in method > Google enabled.
- Authentication > Settings > Authorized domains includes the domain you run from, for example `localhost` for local web runs.

If Firebase config changes, regenerate `lib/firebase_options.dart`:

```bash
flutterfire configure --project=krontech-7fbdb --platforms=web
```
